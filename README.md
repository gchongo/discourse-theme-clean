# discourse-theme-clean

Clean is a lightweight Discourse theme focused on a calm, compact reading and browsing experience.

It currently tweaks topic list density, avatar sizing, tag styling, navigation behavior, and mobile-friendly layout details for a cleaner forum UI.

## Features

- Topic list avatar controls for author and latest poster
- Compact tag and category styling
- Mobile topic list refinements
- Homepage defaults to `/latest`
- Header and navigation polish
